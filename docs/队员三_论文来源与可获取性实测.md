## 0. 一句话结论

论文的**"真实性"没问题**（题目 / 作者 / 年份基本都对得上），但：

1. **"能不能拿到全文"差异极大**，且和"排第几"无关——**排第一的反而只有摘要**；
2. **卡片没有标注来源**，用户无法事先判断这篇来自哪、值不值得点；
3. **来源无法限定**（不能只搜 arXiv / 只搜期刊）；
4. **中文姓名出现"姓 / 名颠倒"**（高畅→畅高、薛爽→爽薛）；
5. **对照表命中与否，结果质量天差地别**（再次印证 BUG-01）。

## 6. 跨主题规律与发现（核心）

1. **来源决定"能否拿到全文"**：arXiv / Springer / SSRN / ChemRxiv 好；TechRxiv 只给摘要；SciTePress / IGI Global 需登录。
2. **同类平台内部也不一致**：ChemRxiv 能拿全文，同类预印本站（主题一第 1 篇）却只有摘要。
3. **卡片未标注来源**：现在只有"查看原文"，用户无法事先判断来源与可获取性 → 建议加**来源标签**。
4. **来源不可限定**：无法只搜某一来源 → 建议加**来源筛选**。
5. **排序只按相关性，未考虑可获取性**：排第一的恰恰是"只有摘要"的预印本，体验差 → 建议排序纳入"**可获取全文**"权重。
6. **中文姓名"姓 / 名颠倒"**：高畅→畅高、薛爽→爽薛；拼音带空格的不受影响的（观察）→ 姓名解析缺陷。
7. **出现双语论文**（Hanspub）：题目/正文/参考文献中英混杂 → 待观察是否常见。
8. **对照表命中 vs 未命中差异巨大**（大语言模型 vs 大预言模型）→ 再次印证 BUG-01；同时说明**演示必须用对照表内主题**。
